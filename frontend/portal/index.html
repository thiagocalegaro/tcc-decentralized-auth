Integrar ao backend · Node.js

Baixar exemplo completo (Node.js) · Funciona com os caminhos padrão e inclui banco de usuários. Execute com node --env-file=.env server.mjs depois de instalar a biblioteca.

1. Instale o pacote @ancora/node gerado por este projeto. Ele ainda não está publicado no npm; veja docs/INTEGRACAO.md.

2. Copie a configuração e acrescente o segredo no ambiente do servidor. Nunca use variáveis públicas do frontend.

3. No backend, crie o cliente e vincule a identidade verificada a um usuário do seu banco.
O exemplo usa uma função findOrCreateUser que você implementa no seu banco, com chave única (issuer, sub). Ela deve retornar o mesmo usuário nos próximos logins.
4. Encaminhe as rotas de autenticação à biblioteca e proteja o conteúdo no servidor.
app.use(async (req, res, next) => {
  if (!await auth.handle(req, res)) next();
});

app.get('/minha-conta', (req, res) => {
  const user = auth.session(req);
  if (!user) return res.redirect('/');
  res.json({ userId: user.userId, address: user.address });
});
5. No seu site, adicione um link para a rota de login.
O site recebe issuer, sub, address e chainId. O ID local userId vem do seu banco. Nenhuma chave privada é compartilhada.


Gerenciar acesso
Trocar o segredo invalida o anterior imediatamente. Desativar bloqueia novos logins e trocas de código; sessões já abertas nos sites não são encerradas.
